# Bank Customer Segmentation

Customer segmentation project based on demographic, financial and credit behavior data.

The project applies unsupervised machine learning to identify distinct groups of banking customers and analyze their behavioral patterns.

## Pipeline

**EDA → Data Cleaning → Feature Engineering → PCA → Clustering → Customer Segmentation**

## Methods

- K-Means Clustering
- Gaussian Mixture Models (GMM)
- PCA
- Isolation Forest
- RFM Segmentation
- Association Rule Mining (Apriori)

## Results

K-Means identified **13 customer segments**, selected using Silhouette, Davies–Bouldin, Calinski–Harabasz and Elbow metrics.

The resulting clusters represent different customer profiles, including high-value, passive and potentially churn-prone clients.

The segmentation can be used for customer profiling, targeted marketing and personalized financial offers.
